# Music

Three text-to-music workflows. All three use nodes built into ComfyUI: no node packs, no patches.

| Workflow | Model | Makes | Licence of the model |
|---|---|---|---|
| **Mine's Stable Audio 3** | Stable Audio 3 Medium | Instrumentals and sound effects, exact length | Stability Community License: commercial use under $1M yearly revenue |
| **Mine's YuE2** | YuE2-3B | Songs with vocals; writes an editable score first | CC BY-NC 4.0: non-commercial |
| **Mine's MiniMax Music 3** | MiniMax Music 3 | Full songs with vocals, up to about 5 min | MiniMax Community License: commercial use under $20M yearly revenue |

Tested on an RTX 5060 Ti (16 GB) with ComfyUI 0.45.6 and PyTorch 2.12 + CUDA 13.0 on Windows.

## 2. First run

1. Drag a workflow from [`workflows/`](../workflows) onto the canvas.
2. Write the prompt on the settings node and run. The result plays in **Result** and is saved under `output/audio/`.

Each workflow's *Guide* note explains its settings.

## Which one to use

| For | Use | Why |
|---|---|---|
| Game BGM, loops, ambience | Stable Audio 3 | Never sings. Exact length. A few seconds per clip, so batches of 4–8 are cheap. |
| Sound effects | Stable Audio 3 | Same model; describe the sound, set a short length. |
| A song with lyrics | YuE2 or MiniMax Music 3 | YuE2: you can see and edit the melody (ABC score). MiniMax: longer songs, three-part caption. |

YuE2 and MiniMax Music 3 are song models. Asked for an instrumental, both still hum or sing: empty lyrics, "no vocals" in the prompt and removing the vocal part from YuE2's score were all tried.

## Tested speed (RTX 5060 Ti 16 GB)

| Workflow | Clip | Time |
|---|---|---|
| Stable Audio 3 | 2 × 90 s | about 10 s (30 s with model load) |
| YuE2 bf16 | 1:52 song, score plan on | 146 s with model load |
| MiniMax Music 3 fp16 | 60 s song | 1–3 min |

With other programs holding VRAM, ComfyUI offloads part of the model to system RAM: it still runs, slower.

## Prompt tips

**Stable Audio 3**: one sentence, style first, then instruments, layers, percussion and mood, ending with `BPM: X. Length: Y seconds`. Name the use: "Japanese visual novel slice-of-life daily BGM in bright J-pop style …" sounded much closer to the genre than a list of instruments alone.

**YuE2**: musical instructions in **style**, only the sung words in **lyrics**, with `[Verse]` `[Chorus]` tags. Length follows the lyrics.

**MiniMax Music 3**: the caption has three parts (*Global Metadata*, *Vocal Details*, *Arrangement*). The song ends when the sections in **lyrics** run out: six section tags gave 13–53 s clips with a 90 s limit.

## Loops

[`tools/make_loop.py`](../tools/make_loop.py) crossfades a clip's last seconds into its start, so it loops without a click:

```sh
python tools/make_loop.py morning.flac morning_loop.flac 3
```

Use ComfyUI's Python (it has `av` and `numpy`). Song models put an intro and an outro on every track; cut them first or the loop restarts audibly.

## Rebuilding the workflows

The three workflow files are generated by [`tools/build_music_workflows.py`](../tools/build_music_workflows.py), which lays them out like the other Mine's workflows. To change a default or a node, edit the script and run it from the repository root:

```sh
python -I tools/build_music_workflows.py workflows
```
